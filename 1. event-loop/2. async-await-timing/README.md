# Async / Await Timing

This lab explains **how `async / await` interacts with the JavaScript event loop**.

---

## What this lab demonstrates

- Code before `await` runs **synchronously**
- Code after `await` is scheduled as a **microtask**
- `await` does NOT block the call stack

---

## How to run

1. Open `index.html`
2. Open DevTools → Console
3. Click **Run Experiment**
